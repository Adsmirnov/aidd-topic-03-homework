# Задание 5. Сравнение AI Coding Agents: Claude Code и GitHub Copilot

| | Claude Code | GitHub Copilot |
|---|---|---|
| Ветка | [`claude-code`](https://github.com/Adsmirnov/aidd-topic-03-homework/tree/claude-code) | [`copilot`](https://github.com/Adsmirnov/aidd-topic-03-homework/tree/copilot) |
| Журнал | `AGENT_LOG.md` в ветке `claude-code` | `AGENT_LOG.md` в ветке `copilot` |
| Модель | Claude Opus 5.5 | `copilot/auto` (выбор модели автоматический) |
| Интерфейс | десктоп-приложение Claude, вкладка Code | VS Code, чат в режиме Agent |

> **Оговорка о беспристрастности.** Текст сравнения подготовил Claude Code — один из сравниваемых агентов. Чтобы снизить предвзятость, выводы опираются на измеримые факты: одинаковые проверки, прогнанные на обеих ветках (раздел 2), число тестов, время, коммиты, записи пользователя. Ошибки Claude перечислены так же подробно, как ошибки Copilot.

Оба агента получили одинаковые по смыслу задачи (промпты Copilot — в `PROMPTS_FOR_SASHA.md` и `chat.json`), работали в отдельных копиях форка, и результаты одного не передавались другому.

## 1. Качество результатов

Требования Claude детальнее, примерно в 3 раза больше пунктов. У Copilot они крупнее и короче, но корректны.

### Задание 3. Модернизация и дефекты

Обе ветки: Django 5.2.18 LTS, Python 3.14, Celery 5.6, psycopg 3, Plotly 7, секреты в `.env`, Postgres 17 в Docker.

| Решение | Claude Code | Copilot |
|---|---|---|
| Удалённый с PyPI SDK Тинькофф | оставил gRPC SDK: зеркало `RussianInvestments/invest-python@0.2.0-beta117`, `--no-deps`, подбор protobuf 5.29 под Python 3.14 | заменил SDK прямыми REST-запросами через `requests`, без зависимости от SDK |
| Адрес API | `invest-public-api.tbank.ru` (настраивается) | `invest-public-api.tinkoff.ru/rest/...` (устаревший домен) |
| Сертификат Минцифры (TLS) | обнаружен запуском и `openssl s_client`; описан как ограничение, проверка TLS не отключалась | не обнаружен: без токена код останавливается до сетевого запроса |
| Регрессионные тесты на дефекты | сначала тест, воспроизводящий дефект (14 упали), затем исправление | тесты исправленного поведения |
| Коммиты «исправления / рефакторинг» | раздельно (5 коммитов) | раздельно (4 коммита) |
| Порты | Postgres 5434 (5432 занят) | Postgres 5433, Redis 6380 — 5433 совпадает с портом другого проекта пользователя (OrderFlow) |
| Лишнее в зависимостях | — | `black`, `isort` в рабочих зависимостях |
| `SECRET_KEY` без `.env` | ошибка запуска (явно) | случайный ключ при каждом старте: после перезапуска все сессии сбрасываются |

Временный тестовый файл с одинаковыми проверками исходных дефектов. Его запускали на каждой ветке и удаляли, в коммиты он не попал.

## 5. Ограничения и проблемы

**Общие для обоих:**
* `tinkoff-investments` удалён с PyPI;
* у пользователя нет токена T-Invest API;
* API Т-Банка работает на сертификате Минцифры;
* у пользователя включён VPN, без которого не работает Claude, а ресурсы Т-Банка с зарубежного IP недоступны.

**Работа с настоящим API не проверена ни у одного агента**, все внешние вызовы проверены только моками.

**Claude Code:**
* платный; по условиям использования доступен с 18 лет;
* ошибки агента:
  * в журнале сначала указал неверное время окончания задания и исправил его по `date`;
  * длинная bash-команда не разобралась (`unexpected EOF`);
  * `Decimal.normalize()` дал `1E+2` в тексте уведомления — поймал тест;
  * логическая ошибка в стратегии со стоп-лоссом — поймала только ручная проверка;
* сначала предложил подключить сертификат Минцифры для приложения; пользователь выбрал более правильный путь;
* первая попытка вынести работу в отдельную сессию сорвалась из-за обрыва интернета у пользователя.

**GitHub Copilot:**
* лимит бесплатного тарифа: на одну домашку ушло 82 % месячных кредитов;
* сбои сервиса: `token expired or invalid: 403`, затем `key is missing`;
* лишняя строка `grpcio==1.51.3` в зависимостях привела к зависанию установки, агент исправил сам;
* предыдущий кандидат, Gemini CLI, не подошёл: Google отключил вход для личных аккаунтов, альтернативы доступны с 18 лет.

## 6. Преимущества и недостатки

**Claude Code**
* ➕ Глубокий анализ: в 3 раза больше требований, вдвое больше дефектов, неочевидные находки.
* ➕ Подход «сначала тест, воспроизводящий дефект».
* ➕ Сам запускал и диагностировал окружение (`openssl`, Docker, браузер).
* ➕ Внимателен к безопасности: не ставил неофициальный SDK, не отключал TLS, не коммитил секреты.
* ➕ Полная реализация функций задания 4.
* ➖ Платный.
* ➖ Ошибки в мелочах (время в журнале, сбой оболочки).
* ➖ Сложное решение с SDK: старое зеркало, подбор версии protobuf.
* ➖ Логическую ошибку стратегии нашёл не тестами, а вручную.

**GitHub Copilot**
* ➕ Бесплатный, встроен в VS Code.
* ➕ Хорошо структурированные коммиты и честные оговорки о непроверенном.
* ➕ Простое и устойчивое решение с REST вместо удалённого SDK.
* ➕ Сам находил и исправлял свои ошибки (`grpcio`, Plotly, `login_required`).
* ➖ Карточка акции падает без токена.
* ➖ Слабые пароли не отклоняются.
* ➖ Изменено поведение поиска в API.
* ➖ Функции задания 4 в минимальном объёме.
* ➖ Много подтверждений; лимит кредитов; сбои сервиса.
* ➖ Неожиданно переписал README.

## 7. Выводы

1. **Анализ существующего кода и восстановление требований** лучше сделал Claude Code: в 3 раза больше проверяемых требований и вдвое больше найденных дефектов (раздел 1). Для аудита незнакомого проекта он полезнее.
2. **Модернизацию** оба агента довели до работающего приложения на актуальном стеке. Решение Copilot с REST проще в поддержке, чем путь Claude со старым gRPC-зеркалом. Но у Claude меньше остаточных дефектов: 0 против 2 на одинаковых проверках, и он нашёл проблему с сертификатом, до которой Copilot не дошёл.
3. **Новую функциональность** Claude реализовал полнее: стоп-лосс, бэктест, метрики, повторное включение уровней. Copilot сделал обязательный минимум и сделал его аккуратно.
4. **Автономность** у обоих высокая. Copilot требует больше ручных подтверждений, но зато пользователь видит каждую команду.
5. **Где кого применять.** Copilot уместен для повседневных задач в редакторе и в стеснённом бюджете: бесплатно, но лимита хватает примерно на одну такую домашку в месяц. Claude Code уместен для больших многошаговых задач: аудит, миграция, функциональность с проверкой окружения.
6. **В обоих случаях результат агента нужно проверять независимо.** Каждый пропустил ошибку, которую не поймали его собственные тесты: 500 на карточке у Copilot, логика стоп-лосса у Claude.

## 8. Дополнение: проверка с настоящим T-Invest API (2026-10-25)

По требованию преподавателя ветку `claude-code` проверили с настоящим токеном (только чтение). Подробности — в `ANALYSIS.md`, раздел 22.

* **Claude Code:**
  * подключение с проверкой TLS через корневой сертификат Минцифры, подключённый только для приложения;
  * загружено 1913 акций и все цены;
  * карточка с графиком из API работает;
  * на реальной цене SBER автоматически сработали уведомление (один раз, без дублей) и покупка стратегии.
* **GitHub Copilot:** получил то же задание и те же ограничения, но **до реальных данных не дошёл**:
  * на `CERTIFICATE_VERIFY_FAILED` остановился и спросил решение (хорошо), но ошибочно принял сертификат Минцифры за «TLS-перехват в сети»;
  * после разрешения пользователя скачал корневой сертификат с `gu-st.ru` и сверил две копии между собой, а с цепочкой сервера API — нет;
  * TLS прошёл, но запрос вернул HTTP 404: REST-адрес собирался неверно ещё с задания 3, моки этого не показали;
  * правку адреса сделал, но проверить не смог: перестал работать терминал VS Code (агент не получал вывод команд), затем закончились бесплатные кредиты (21 → 1,5);
  * правка закоммичена с пометкой «не проверено».

**Настоящие данные выявили два дефекта исходного кода**, которые не нашёл ни один агент на этапе анализа и тестов на моках:
* Д-20: тикер не уникален между биржами (`T`, `DIOD`, `ROST`), `add_shares` падает с `IntegrityError`;
* Д-21: у бумаг без торгов цена 0 и время 1970-01-01.

В ветке `claude-code` оба исправлены.

**Оставшиеся риски ветки `copilot` по чтению кода.** Это не запуск, а анализ; адрес REST и сертификат уже разобраны выше:
* в модели `Share` у тикера осталось `unique=True`, поэтому загрузка на настоящих данных, по всей видимости, упадёт на `DIOD`;
* нулевая цена из API пропускается при записи истории, но сохраняется как текущая цена и передаётся в проверку уровней, где может вызвать ложное срабатывание «≤ X»;
* CA bundle в коде не настроен: агент передавал его только разово, в команде.

Вывод к разделу 7: тесты на моках у обоих агентов не заменили проверку на реальных данных. Два дефекта исходного проекта и ошибка в REST-адресе Copilot проявились только при живом запуске. Ограничение бесплатного тарифа оказалось решающим: на 7 промптов задания и одну проверку с API 200 месячных кредитов Copilot не хватило.
